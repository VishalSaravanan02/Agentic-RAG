# Agentic Multi-Hop RAG

MSc Dissertation — COMP702, University of Liverpool  
Student: Vishal Saravanan (201900556)  
Supervisor: Dr Terry Payne

## Project Overview
An agentic multi-hop Retrieval-Augmented Generation system that makes 
every retrieval decision explicitly and adaptively through five named 
decision mechanisms, evaluated against a single-hop RAG baseline on HotpotQA.
